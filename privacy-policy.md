# Privacy Policy — Sickbay Health Display

This application is a personal, single-user hobby project built by Angus (github.com/LivingAngus) to display his own Oura Ring health data on custom hardware.

- This application is not distributed publicly and is not intended for use by anyone other than its developer.
- Data retrieved from the Oura API (activity, sleep, readiness, heart rate, and related metrics) is used solely to display readings on a personal hardware device on the developer's home network.
- No data is sold, shared with third parties, or used for any purpose other than personal display.
- Data is cached temporarily on personal hardware for display purposes and is not permanently stored or backed up elsewhere.
